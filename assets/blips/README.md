# Ícones do mapa de GTA V

Fonte: [Cfx.re — Blips](https://docs.fivem.net/docs/game-references/blips/).
Arquivos PNG originais obtidos em `https://docs-backend.fivem.net/blips/radar_<nome>.png`.

Os ícones ficam disponíveis localmente, inclusive offline. O nome de cada arquivo corresponde ao sprite original sem o prefixo `radar_`.

O aplicativo identifica o tipo da propriedade pelo nome quando não há um tipo escolhido. No cadastro também é possível selecionar explicitamente o tipo, permitindo usar um nome personalizado para o fliperama, agência e demais propriedades.
