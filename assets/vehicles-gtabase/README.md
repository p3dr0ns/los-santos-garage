# Imagens automáticas dos veículos

Fotos de referência extraídas dos metadados `og:image` das páginas individuais
do [GTA Base](https://www.gtabase.com/grand-theft-auto-v/vehicles/).
Imagens de GTA V / GTA Online, Rockstar Games; seleção editorial GTA Base.

`../vehicle-images.js` registra a página de origem, a URL original e o arquivo
local por código de modelo. Variantes Drift sem foto própria usam a imagem do
modelo base, com `sharedWith` preenchido e aviso correspondente na ficha.

Atualização: `scripts/update-vehicle-images.ps1`. Os arquivos locais permitem
uso offline e evitam depender de hotlinks. Não há imagens enviadas pelo usuário,
camadas de personalização ou alterações de cor nessas imagens.
