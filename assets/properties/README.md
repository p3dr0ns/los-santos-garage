# Fachadas das propriedades

Imagens do GTA Online, Rockstar Games, obtidas do GTA Wiki. O arquivo
`../property-images.js` registra a propriedade, a página de origem e a URL
de cada imagem. As fotos são mantidas localmente para não depender de
carregamento externo. Prédios com vários apartamentos compartilham a fachada.

Os cards de garagens e o catálogo Eyefind mostram a parte externa. A decoração
interna continua disponível no formulário e na visualização das vagas.
Garagens sem endereço identificado mostram um convite para vincular o imóvel.

Atualização: `./scripts/update-property-images.ps1`. Para apenas verificar
os arquivos existentes sem acessar a rede, use `-Offline`.
