# Fluxo de trabalho

- Após alterar este projeto, execute as verificações adequadas e publique as mudanças no GitHub Pages. O usuário autorizou o deploy em toda alteração; não pare na implementação local.
- A publicação usa o workflow `.github/workflows/pages.yml`, acionado por push na branch `main`. Confirme o resultado do workflow e informe o endereço publicado.
